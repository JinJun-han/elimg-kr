# ELIM G MERGE PRIORITY v1.0

업데이트: 2026-09-30

## 통합 원칙
1. 사용자 혼란이 큰 중복부터 정리한다.
2. 공식 도메인과 대표 운영본을 우선한다.
3. 콘텐츠를 먼저 보존한 뒤 리디렉션한다.
4. 고유 운영주체가 있는 협력 사역은 흡수하지 않는다.

## 1순위 — 메인 플랫폼 중복 정리
대상:
- 엘림G 허브
- 엘림G 플랫폼
- 원스톱 서비스
- 엘림G 미션
- ELIMGS
- 엘림G 웹
- ELIMGW
- ELIMG GMMC
- 글로컬 브릿지

대표: https://elimg.kr

이유: 모두 ELIM G 전체를 대표하려는 성격이 강해 브랜드 혼란이 가장 크다.
조치: 좋은 섹션/문구/기능을 elimg.kr로 선별 이관 → 구주소는 대표 주소로 이동.

## 2순위 — 취업·인재 기능 통합
대상:
- 김해 취업 매칭
- 글로컬 취업 매칭
- 인재 매칭

대표: jobs.elimg.kr

이유: 사용자 목적이 명확하고 기능 중복이 크다.
조치: 구직자/기업/유학생 흐름을 하나의 Jobs 서비스로 통합.

## 3순위 — 한국어·AI 학습 통합
대상:
- 중국어권 사역
- 글로컬 중국어
- AI 한국어
- AI Korean
- 엘림G 한

대표 후보: learn.elimg.kr

이유: 언어·AI 교육을 한 Learning Hub로 묶으면 국가별 학습 사이트를 연결하기 쉽다.
조치: 공통 학습 허브 구축 후 국가/언어별 Satellite를 연결.

## 4순위 — CBMC 중복 정리
대상:
- 한마음 일정
- 한마음 회칙
- CBMC 비즈 브릿지

대표: gimhae-cbmc.netlify.app

이유: 별도 사이트보다 공식 CBMC 사이트 내부 메뉴가 적합.
조치: 일정/회칙/비즈브릿지를 내부 메뉴로 흡수.

## 5순위 — 성경·콘텐츠 정리
대상:
- IMPACT Bible → 엘림G 성경연구
- 레위기 스터디 → IMPACT 레위기
- 은혜감사 → GraceOK

이유: 동일 주제별 대표본이 이미 존재.
조치: 콘텐츠 보존 후 대표본에 통합.

## 6순위 — 지역 생활·힐링 정리
대상:
- 김해 생활 정보
- 김해라이프 정보
- 참빛교회

- 글로벌 이주

대표 후보:

이유: 지역/주제별 공식 경로를 먼저 만든 뒤 흡수해야 안전하다.
